# portfolio-josue
Portafolio profesional de Josue Manuel Villarruel Flores

El CV público se enfoca en soporte TI y automatización: una página, experiencia
principal y dos proyectos relevantes. El catálogo completo permanece en el sitio.

Para regenerar el PDF y `cv.html`, edita el bloque `resume` de
`assets/cv-content.json` y ejecuta `python3 scripts/build_cv.py` (ReportLab y fuentes
DejaVu). El generador comprueba que el documento conserve una sola página.

La identidad actual utiliza el monograma JV de trazo fluido (opción B). Revisa
`SECURITY-NOTES.md` antes de publicar información o capturas.
