# Privacidad del portafolio

Este repositorio publica únicamente información profesional seleccionada.

- No se debe publicar correo personal, teléfono, domicilio, credenciales ni identificadores privados.
- El CV disponible en el sitio es únicamente la versión pública sanitizada.
- Los casos de soporte deben mantener anonimizados datos de usuarios, equipos, tickets, infraestructura y clientes cuando corresponda.
- Antes de subir capturas o archivos, se revisan datos visibles y metadatos para evitar exposición accidental.
